# Radio-SFS

A mod that lets you listen to the radio ingame.

## Requirements and Dependencies

## Installation

- Install Radio-SFS.dll from the latest release into your SFS mod folder. 
- Open the game once. This will generate the necessary folders and config for the mod.
- Select a radio URL from the menu; if none is specified (or if it is invalid), the default music will be played.
